# Octo City Sky Lights

A small HTML and CSS project that builds a colorful city skyline from styled elements and gradients. It demonstrates how CSS can create a visual scene and use a media query to respond to viewport width.

## View the page

Open [`port_1/portInd.html`](port_1/portInd.html) in a web browser. The page links to its stylesheet in the same directory, so no build tools or dependencies are required.

## Responsive styling

The stylesheet includes a breakpoint at `1000px`. At narrower viewport widths, the city changes to a darker, muted color palette. The buildings are still arranged with the same layout; the media query changes the scene's colors rather than rearranging its elements.

## Project files

- `port_1/portInd.html` — markup for the skyline.
- `port_1/styleport1.css` — building shapes, colors, gradients, and the viewport-width media query.
